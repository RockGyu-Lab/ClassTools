# ClassTools

수업과 담임 업무에 쓰는 작은 도구 모음입니다.

## 쓰는 방법
- 인터넷이 되면: GitHub Pages 주소로 열면 됩니다(설치 필요 없음).
- 인터넷이 없으면: 저장소를 내려받아 `index.html`을 더블클릭해 엽니다.

## 다른 컴퓨터에서 이어서 작업하기
```
git clone https://github.com/RockGyu-Lab/ClassTools.git
```

## 개인정보
학생 명단 등 개인정보는 이 저장소에 넣지 않습니다. 도구를 쓸 때 화면에 넣으면 그 기기의 브라우저에만 저장됩니다.
